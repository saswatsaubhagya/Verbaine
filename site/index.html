Install in a minute

Verbaine isn't notarized yet, so macOS asks you to approve it once.

  1. Download the latest release and move Verbaine to Applications.
  2. Open it. macOS says it can't verify the app. That's expected.
  3. In System Settings → Privacy & Security, click Open Anyway.
  4. Allow Accessibility when asked, so Verbaine can read your selection.

Needs an Apple Silicon Mac, macOS 26.4 or later, and Apple Intelligence turned on.
